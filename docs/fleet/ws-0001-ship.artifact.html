Things to know before you decide (stated, not hidden)

  • Panel is one version behind the code. The management panel is not in the public source; it was mirrored out of the running 1.0.72 image, as the runbook requires. So this 1.0.73 server ships the 1.0.72 panel. Upstream's new Devin login screen will not appear in the UI until upstream publishes a 1.0.73 image we can mirror from. Everything the panel does today keeps working.
  • Not reproducible from public source alone, for the same reason. Same disclosure as the last two deploys.
  • The known scheduler defect (agent-os #717) is unchanged. The early-warning de-preference is still dead code on the Ark's fast path. That is its own workstream (ws-0003) and is neither better nor worse in this image.
  • "Newest models" do not depend on this deploy. Home already downloads the live model catalog every 3 hours; the Ark's log shows it doing so today, and Fable 5.1 and Opus 5.5 are already in that catalog. Separately: the catalog has dropped gpt-5.4 and gpt-5.4-mini, which agent-os still references in places — flagged for agent-os, not fixed by this image.
  • The branch tip will be two docs-only commits past the image (this write-up and the close-out). The binary is unaffected.
  • Reached the Ark over Tailscale, not the LAN address — the LAN path from the laptop was not answering this session. Same host, same key, same user.

What happens on each answer

Ship: under the fleet lock, the compose file is pointed at the new tag, the container is recreated, and the post-deploy checks from the runbook are run (container healthy, nodes re-register, one real Claude request through a node). Rollback is one compose edit back to the tag above, verified by image ID first. Hold: nothing moves; the image stays on the Ark, harmless, until you say otherwise.
